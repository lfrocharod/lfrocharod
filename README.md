#### Projects

**[fantasy-dashboard](https://github.com/lfrocharod/fantasy-dashboard)** · [live demo](https://fantasy-dashboard-demo.vercel.app)

A decision engine for four fantasy leagues: UEFA Champions League Fantasy, FPL Draft, and ESPN fantasy football and basketball. It pulls each game's data on a schedule, projects every player's points, and turns them into decisions (who to captain, start, sign, stream, trade or bench), with the reasoning next to the number. A learned FPL model is judged by a walk-forward backtest and graded live every gameweek.

`FastAPI` `SQLAlchemy` `PostgreSQL` `React 19` `TypeScript` `scikit-learn` `integer programming` `Vercel`

**[wedding-invitation-template](https://github.com/lfrocharod/wedding-invitation-template)** · [live demo](https://lfrocharod.github.io/wedding-invitation-template/)

A mobile-first wedding invitation site: it opens from an envelope, plays background music, and takes RSVPs into Google Sheets, with email, WhatsApp or Telegram notices. All of it is configured from one file and baked into static HTML at build time.

`Vite` `JavaScript` `SCSS` `Google Apps Script` `Playwright` `GitHub Pages`
